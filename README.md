# 双电脑分布式 iPad 腾讯会议题目监控 + DeepSeek R1 自动化解题系统

本项目采用**双电脑分布式架构（主电脑 + 辅助电脑）+ iPhone 手机端免触碰实时看答案 + 主电脑代码题自动入剪切板**，专为严格无痕与高稳定性要求设计：

```
+-----------------------------------------------------------------------------------+
| 【主电脑 (Master PC)】                                                             |
| - 运行腾讯会议 (查看 iPad 共享画面)                                                |
| - 超轻量后台，零浏览器痕迹，零 Playwright/Chromium 驻留                             |
| - 纯快捷键截题：按 [Ctrl + Shift] 立即截取题目区域并毫秒级送出                     |
| - 局域网内自动 UDP 发现辅助电脑，无需手动输入 IP                                   |
| - 内置轻量剪切板接收器 (端口 8081)：代码题答案出炉时自动写入主电脑剪切板           |
+-------------------+--------------------------------------+------------------------+
                    | 1. HTTP POST 上传题目 (局域网)        ^ 3. 代码题答案自动推回
                    v                                      |    (直接 Ctrl+V 粘贴)
+-------------------+--------------------------------------+------------------------+
| 【辅助电脑 (Secondary PC)】                                                        |
| - 启动后台服务与 UDP 广播宣告                                                     |
| - 驱动持久化 Chrome 登录态，全自动接入 DeepSeek Web (R1 深度思考模式)              |
| - 严格执行系统规则：保留原题题号、纯答案无推导、代码包裹且无注释                   |
| - 防卡死/防堆积引擎：自动清除历史残留、等待上传就绪、物理模拟点击与重试            |
| - 答案提取引擎：提取完整 Markdown 代码块结构并过滤思考过程                         |
| - 托管 iPhone 实时大字看板 HTTP 服务 (8080端口)                                    |
+------------------------------------------+----------------------------------------+
                                           | 2. HTTP 轮询 (每 800ms 自动静默拉取)
                                           v
+-----------------------------------------------------------------------------------+
| 【苹果手机 (iPhone 看板)】                                                         |
| - Safari 扫码即开，OLED 纯黑背景防烧屏省电                                         |
| - 内置 WakeLock API：放在手机支架上永不息屏、永不休眠                              |
| - 全程零触碰：DeepSeek 算完答案后毫秒级自动跳出                                    |
| - 完整 Markdown 渲染引擎 (marked.js + highlight.js)：单选大字 + 编程题语法高亮     |
+-----------------------------------------------------------------------------------+
```

## 目录结构说明

```text
ipad_deepseek_solver/
├── master_pc/                     # 主电脑独立工作目录（只需拷贝此文件夹至主电脑）
│   ├── master_config.py           # 主电脑配置文件 (热键、端口、临时路径等)
│   ├── master_main.py             # 主电脑主程序 (含快捷键截题 + 剪切板接收器)
│   ├── discovery.py               # 局域网 UDP 自动寻找辅助电脑
│   ├── roi_selector.py            # 半透明鼠标交互式框选题目区域
│   ├── requirements_master.txt    # 主电脑依赖 (仅 requests, pillow, numpy, keyboard, mss)
│   └── run_master.bat             # 主电脑一键双击启动脚本
│
├── secondary_pc/                  # 辅助电脑独立工作目录（只需拷贝此文件夹至辅助电脑）
│   ├── secondary_config.py        # 辅助电脑配置 (系统提示词、端口、R1模式开关等)
│   ├── main_secondary.py          # 辅助电脑主启动调度器
│   ├── secondary_server.py        # iPhone 看板服务 + 题目接收接口 + 代码反推主电脑
│   ├── deepseek_bot.py            # Playwright DeepSeek Web 自动化机器人 (R1 深度思考)
│   ├── requirements_secondary.txt # 辅助电脑依赖 (playwright, pillow, qrcode)
│   └── run_secondary.bat          # 辅助电脑一键双击启动脚本
│
├── test_dashboard.py              # 主机本地测试工具（无需第二台电脑即可全面测试）
├── test_dashboard.bat             # 一键双击本地测试启动脚本
└── README.md                      # 本说明文档
```

## 🚀 本地开发与测试（无需第二台电脑，直接在当前主机测试！）

如果你正在当前主机上开发或调试，**完全不需要每次把代码拷贝到辅助电脑**：

双击运行根目录下的 **`test_dashboard.bat`**（或桌面的 **`测试看板与写字板.bat`**）：
1. **手机/浏览器看题测试**：终端会输出局域网 IP 与二维码，iPhone 扫码或在电脑浏览器按 `o` 即可直接打开看板；
2. **全题型一键切换**：
   - 按 `1`：模拟单选题（同行同格式自然字体呈现，如 `【第1题】 C`）；
   - 按 `2`：模拟多题清单（如 `【第1题】 A ... 【第5题】 True`，保留原生大小写）；
   - 按 `3`：模拟 Java 编程题（完整缩进换行 + 题号置顶）；
   - 按 `4`：模拟 Python 算法题；
   - 按 `5`：模拟概念问答题 / 简答题（TCP三次握手条理化解析）；
   - 按 `6`：模拟综合大题（含小题与完整代码块）；
   - 按 `7`：模拟“解题中等待状态”（黄色呼吸指示灯）；
   - 按 `8`：手动输入任意文字/代码推送到看板；
   - 按 `9`：模拟 LeetCode 138 实测题（完整换行代码）；
3. **剪切板联动测试**：
   - 默认状态：系统剪切板完全不受影响（默认不黏贴）；
   - 提取答案：随时按【双击 Ctrl】、【Ctrl + Q】或【F9】，即可将当前题目答案直接写入剪切板；
   - 按 `n`：一键打开记事本 / 写字板，按 `Ctrl + V` 验证粘贴！
   - 按 `q`：退出测试。

## 极速部署与使用指南（双机实战运行）


### 第一步：配置并启动【辅助电脑 (Secondary PC)】

1. **环境准备**：
   在辅助电脑上打开终端或命令提示符，进入 `secondary_pc` 目录：
   ```bash
   cd secondary_pc
   pip install -r requirements_secondary.txt
   playwright install chromium
   ```

2. **一键启动**：
   双击运行 `run_secondary.bat`（或执行 `python main_secondary.py`）。
   - **首次启动登录**：系统会自动弹出一个独立的 Chrome 浏览器并打开 `https://chat.deepseek.com`。请在浏览器中完成登录（微信扫码或手机号验证）。登录态将永久保存在 `deepseek_user_data` 目录中，后续启动无需再登录。
   - **自动化系统提示生效**：程序启动时会自动向 DeepSeek 发送严格设定的系统规范提示词（强制保留题号、单选多选仅答案、代码包裹且无注释）。
   - **手机看板二维码**：终端会输出局域网 IP 与 iPhone 看板二维码。

---

### 第二步：配置【iPhone 手机看答案】

1. 确保 iPhone 与辅助电脑连接在**同一个 Wi-Fi 网络**下。
2. 打开 iPhone 相机直接扫描辅助电脑终端打印的二维码，或在 Safari 浏览器中输入对应的局域网网址（例如 `http://192.168.x.x:8080`）。
3. **免触碰特性**：
   - 页面开启后会自动激活 **WakeLock 屏幕常亮**（顶部指示灯显示绿点“⚡ 屏幕常亮已保持”），手机放在支架上绝不锁屏。
   - 答案实时自动刷新：辅助电脑 DeepSeek 生成答案后，手机端将在 0.8 秒内无感跳出最新题号与答案。
   - 单选极简模式显示 `56px` 超大荧光绿字号；长文本与编程题以深色 GitHub Dark 风格完整渲染高亮代码块。

---

### 第三步：配置并启动【主电脑 (Master PC)】

1. **环境准备**：
   将 `master_pc` 文件夹（或压缩包）解压到主电脑。进入 `master_pc` 目录：
   ```bash
   cd master_pc
   pip install -r requirements_master.txt
   ```
   > 主电脑无需安装 Playwright 或 Chromium，极简无痕。

2. **一键启动**：
   以管理员身份双击运行 `run_master.bat`（或执行 `python master_main.py`）。
   - **全自动局域网对齐**：主电脑启动后会自动监听局域网 UDP 广播，1~2 秒内自动识别辅助电脑的 IP 和端口并建立链接，无需手动输入 IP。
   - **交互式框选监控区域**：屏幕上会出现半透明遮罩，按住**鼠标左键**在腾讯会议画面中拖拽框选出 iPad 题目的显示区域，松开后按 **Enter 键确认**。区域坐标将自动记录在 `master_roi_config.json`，下次启动可直接复用。
   - **剪切板接收服务就绪**：主电脑后台自动监听端口 `8081`。

## 快捷键与使用工作流

| 快捷键 / 动作 | 作用 | 说明 |
| :--- | :--- | :--- |
| **`Ctrl + Shift`** 或 **`F8`** | **截题并发送** | 按下瞬间截取腾讯会议中的 iPad 题目区域，毫秒级送往辅助电脑解题 |
| **手机 / 浏览器看板** | **实时看答案** | 舒适护眼正常字号（#f0f6fc），题号与答案同行同格式呈现，保留自然大小写，代码自动换行无横向滚动条 |
| **`双击 Ctrl`** 或 **`Ctrl + Q`** 或 **`F9`** | **按需拷贝答案** | **默认不改动剪切板**（避免误覆盖日常复制）。按快捷键后，立即将当前题目内容（纯净代码或选择/简答答案）拷贝进剪切板 |
| **主电脑 `Ctrl + V`** | **直接粘贴** | 提取后直接在考试网页、写字板或 IDE 中粘贴到位即可 |

## 系统核心规范与防卡死保障

1. **系统提示词规范**：
   ```text
   【系统规则设定】从现在起，你是一个极度严苛的题目求解引擎，请严格遵守以下最高输出规范：
   1. 必须保留原题题号（例如：【第1题】C 或 1. C；若包含多道小题则逐一按题号标出，如 1. A 2. D）；
   2. 选择题/填空题：只输出【题号 + 最终答案/选项】（严禁输出任何解题过程、推导或解析）；
   3. 代码/编程题：只输出【题号 + 完整源代码】，源代码必须使用 Markdown 代码块包裹（如 ```java ... ```），以保留缩进和语法高亮。代码中严禁包含任何注释（严禁 //、/* */、# 等）。代码前后严禁输出任何思路说明或废话！
   如果完全理解，请仅回复：【收到，题号与答案输出规范已生效】
   ```
2. **纯图片提交**：开局系统提示确立规则后，后续题目采用纯图片发送（`DEFAULT_PROMPT = ""`），无需发送额外废话。
3. **输入框堆叠与未发送防卡死机制**：
   - 发送前自动清空输入框历史残留（包括异常挂起的未发送缩略图）。
   - 采用上传遮罩层主动轮询（等待上传进度完成）。
   - 物理模拟点击发送按钮，失败时自动退避 Enter 键重试最多 4 次。
   - 发送失败后自动执行 Purge 清洗，绝不会导致后续图片在输入框累加堆叠。
4. **主电脑剪切板安全机制**：
   - 采用纯 Win32 `ctypes` 原生内存操作，不弹窗、零依赖外部软件。
   - 辅助电脑从上传请求中动态读取主电脑 IP，网络拓扑变化无需重新配置。
