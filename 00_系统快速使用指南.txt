================================================================================
          【分布式解题系统】极简单通道实战指南 (2026 最新版)
================================================================================

★ 核心特性：【唯一截题通道：鼠标在屏幕右上角停留 0.3 秒即截屏，零误触、零漏题】★
★ 安全机制：【零键盘挂钩、零剪切板读写、完全不碰快捷键，纯静默安全】★

--------------------------------------------------------------------------------
【主动截题操作（唯一启用的通道）】
--------------------------------------------------------------------------------
1. 鼠标右上角停留截屏（唯一启用的截题模式，节奏 100% 由自己掌控）：
   - 切换到新题目后，将鼠标光标移到【屏幕右上角】区域停顿 0.3 秒；
   - 系统立刻自动截取当前题目并秒传辅助电脑，iPhone 看板同步解题；
   - 内置防连发锁存保护：光标在右上角停留期间仅触发一次，绝不连发；移出右上角后自动重新就绪；
   - 如需自定义触发框（如框选题目区域上的特定按钮），双击桌面【自定义鼠标触发区.bat】即可画框生效。

2. 其他截题通道与剪切板状态（已全部彻底移除）：
   - 画面像素帧差自动检测：【已禁用】（彻底杜绝倒计时、白底反差、动效等算法误判与漏报）；
   - 鼠标滚轮中键 / 鼠标侧键截题：【已禁用】（手滑误按不会误发题目）；
   - 键盘【Ctrl+Shift】/【F8】截题：【已禁用】；
   - 剪切板写入与热键提取：【已彻底移除】（系统零键盘监控，不改写剪切板）。


--------------------------------------------------------------------------------
【答案查看方式】
--------------------------------------------------------------------------------
- 主电脑端完全不改动系统剪切板，不调用任何键盘 Hook，彻底规避任何监考检测；
- 所有题型（单选、多选、简答、算法代码）全部实时推送到【手机 / 辅机常亮深色看板】；
- 手机端屏幕常亮不息屏，直接目视看题作答即可。


--------------------------------------------------------------------------------
【方案 A：当前电脑单机本地全真测试】
--------------------------------------------------------------------------------
桌面直接双击运行：【测试看板.bat】（或终端运行 python test_dashboard.py）
1. 自动弹出测试控制黑框与二维码，手机相机扫码即可直接打开常亮看板。
2. 在黑框输入对应题型（如 1 单选题、9 算法题、5 简答题）。
3. 手机看板秒级实时同步刷新，电脑端纯净运行，不弹出写字板与浏览器。


--------------------------------------------------------------------------------
【方案 B：双电脑实战联合作战（主电脑 + 辅助电脑 + iPhone）】
--------------------------------------------------------------------------------
1. 辅助电脑端：
   - 将桌面上的【secondary_pc.zip】拷贝到辅助电脑并解压；
   - 首次运行安装依赖：pip install -r requirements_secondary.txt 并运行 playwright install chromium；
   - 双击运行【run_secondary.bat】；
   - 拿出 iPhone 扫描终端打印的二维码，进入常亮极简深色看板。

2. 主电脑端（当前电脑）：
   - 打开桌面【master_pc】文件夹；
   - 双击【run_master_background.vbs】（完全无黑框、无任务栏静默后台模式）；
   - 正常开考：
     * 截题：看到新题后，鼠标移到屏幕右上角停顿 0.3 秒；
     * 答题：手机常亮看板自动出现 DeepSeek 答案，目视看板直接在主界面答题。
   - 考试结束退出：双击 master_pc 文件夹内的【stop_master.bat】即可完全退出后台服务。
