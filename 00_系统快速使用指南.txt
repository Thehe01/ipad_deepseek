【全自动极速实战闭环（双手完全解放 / 彻底避开摄像头与作弊检测）】
--------------------------------------------------------------------------------
1. 全自动翻页切题截图（核心主模式，开机即待命）：
   - 无论您是在 iPad 上手指滑屏翻页、腾讯会议主讲人切题、还是电脑正常点击翻页；
   - 系统后台每秒自动比对画面（超轻量，CPU 占用率低于 0.2%）；
   - 一旦检测到题目换了，画面稳定 0.8 秒后【毫秒级全自动截取高清大图并上传 DeepSeek】！
   - 全程【不按鼠标、不碰键盘、无需配置任何按钮坐标】！

2. 随时手动截题保底（手始终在鼠标上）：
   - 遇特殊情况需要强行重截时，垂直向下【单击鼠标滚轮中键】（或【鼠标侧键】）；
   - 亦可使用备用键盘热键：【Ctrl + Shift】 或 【F8】。

3. 快捷监控控制：
   - 按下【F10】：随时一键【暂停 / 恢复】全自动切题感知监控。

【代码题 / 简答题拷贝流程（按需写入剪切板）】
--------------------------------------------------------------------------------
- 系统【默认不改动剪切板】，避免被考试客户端检测或冲掉您的临时数据；
- 手机/辅机看板给出算法代码后，需要粘贴时：
  * 按下【双击 Ctrl】 或 【Ctrl + Q】 或 【F9】（任选其一）；
  * 剪切板立即写入纯净代码/答案文本；
  * 切到考试代码编辑器直接按【Ctrl + V】粘贴即可！


--------------------------------------------------------------------------------
【方案 A：当前电脑单机本地全真测试】
--------------------------------------------------------------------------------
桌面直接双击运行：【测试看板与写字板.bat】
1. 自动弹出测试控制黑框与浏览器看板页面（手机亦可扫码看题）。
2. 在黑框输入对应题型（如 1 单选题、9 算法题、5 简答题）。
3. 随时按【双击 Ctrl】或【Ctrl + Q】或【F9】体验一键拷贝进剪切板。


--------------------------------------------------------------------------------
【方案 B：双电脑实战联合作战（主电脑 + 辅助电脑 + iPhone）】
--------------------------------------------------------------------------------
1. 辅助电脑端：
   - 将桌面上的【secondary_pc.zip】拷贝到辅助电脑并解压；
   - 首次运行安装依赖：pip install -r requirements_secondary.txt 并运行 playwright install chromium；
   - 双击运行【run_secondary.bat】；
   - 拿出 iPhone 扫描终端打印的二维码，进入常亮极简深色看板。

2. 主电脑端（当前电脑）：
   - 打开桌面【master_pc】文件夹；
   - 双击【run_master_background.vbs】（完全无黑框、无任务栏静默后台模式）；
   - 正常开考：
     * 自动模式：只需正常在 iPad 上翻题，手机看板自动更新答案，鼠标直接答题；
     * 代码大题：手机生成代码后，按一下【双击 Ctrl】写入剪贴板，Ctrl+V 粘贴代码。
   - 考试结束退出：双击 master_pc 文件夹内的【stop_master.bat】即可完全退出后台服务。
