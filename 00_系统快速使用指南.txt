================================================================================
          【分布式解题系统】极速无痕实战指南 (2026 最新版)
================================================================================

★ 核心防作弊特性：选择题【全程手不离鼠标、不碰键盘、不写剪切板】★

--------------------------------------------------------------------------------
【选择题极速盲操闭环（零键盘 / 避开摄像头与作弊检测）】
--------------------------------------------------------------------------------
1. 截题触发：
   - 右手握住鼠标，垂直向下【单击鼠标滚轮中键】（或【鼠标侧键】）；
   - 系统瞬间截取当前 iPad 会议/题目区域，毫秒级上传辅机与 DeepSeek；
   - （备用键盘热键：【Ctrl + Shift】 或 【F8】）。
2. 看板读答案：
   - 视线轻瞥立在屏幕旁的 iPhone 手机看板（例如常亮显示：【第1题】 C）；
3. 鼠标作答：
   - 鼠标左键直接移至考试页面的对应选项并单击；
   - 期间【键盘完全不碰、剪贴板完全不碰】，100% 模拟正常考生做选择题习惯！


--------------------------------------------------------------------------------
【代码题 / 简答题拷贝流程（按需写入剪贴板）】
--------------------------------------------------------------------------------
- 系统【默认不改动剪贴板】，避免被考试客户端检测或冲掉您的临时数据；
- 手机/辅机看板给出算法代码后，需要粘贴时：
  * 按下【双击 Ctrl】 或 【Ctrl + Q】 或 【F9】（任选其一）；
  * 剪切板立即写入纯净代码/答案文本；
  * 切到考试代码编辑器直接按【Ctrl + V】粘贴即可！


--------------------------------------------------------------------------------
【方案 A：当前电脑单机本地全真测试】
--------------------------------------------------------------------------------
桌面直接双击运行：【测试看板与写字板.bat】
1. 自动弹出测试控制黑框与浏览器看板页面（手机亦可扫码看题）。
2. 在黑框输入对应题型（如 1 单选题、9 算法题、5 简答题）。
3. 随时按【双击 Ctrl】或【Ctrl + Q】或【F9】体验一键拷贝进剪切板。


--------------------------------------------------------------------------------
【方案 B：双电脑实战联合作战（主电脑 + 辅助电脑 + iPhone）】
--------------------------------------------------------------------------------
1. 辅助电脑端：
   - 将桌面上的【secondary_pc.zip】拷贝到辅助电脑并解压；
   - 首次运行安装依赖：pip install -r requirements_secondary.txt 并运行 playwright install chromium；
   - 双击运行【run_secondary.bat】；
   - 拿出 iPhone 扫描终端打印的二维码，进入常亮极简深色看板。

2. 主电脑端（当前电脑）：
   - 打开桌面【master_pc】文件夹；
   - 双击【run_master_background.vbs】（完全无黑框、无任务栏静默后台模式）；
   - 正常开考：
     * 选择题：按一下【鼠标滚轮中键】截题 -> 瞥一眼手机看板 -> 鼠标左键选答案；
     * 代码题：按一下【鼠标滚轮中键】截题 -> 看板生成代码 -> 【双击 Ctrl】一键写入剪贴板 -> Ctrl+V 粘贴代码。
   - 考试结束退出：双击 master_pc 文件夹内的【stop_master.bat】即可完全退出后台服务。
